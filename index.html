✦ ИИ-помощник

Без ключа помощник отвечает на типовые вопросы встроенными расчётами и работает без интернета. С ключом Claude он понимает любые вопросы о ваших тратах.
Ключ создаётся в console.anthropic.com → API Keys. Он хранится только на этом телефоне и не попадает в резервную копию. Запросы оплачиваются с вашего аккаунта Anthropic. Когда помощник отвечает с ИИ, ваши траты (суммы, магазины, заметки) отправляются в Anthropic. Не вводите ключ на чужих устройствах.

💳 Apple Pay

После оплаты откроется MIDAS с суммой и магазином, останется нажать на категорию.
Ваша ссылка для автоматизации:
1. Приложение «Команды» → «Автоматизация» → «+» → «Транзакция».
2. Выберите карты и «Запускать немедленно», затем «Далее».
3. «Новая пустая автоматизация» → действие «Открыть URL».
4. Вставьте ссылку выше. СУММА замените на переменную «Сумма», МАГАЗИН на «Продавец» (нажмите на слово → «Выбрать переменную»).

Курсы валют

Курсы обновляются сами раз в 6 часов. Источник: open.er-api.com. Старые траты пересчитываются по текущему курсу.
